## Design Intent

- `s01`: key message is founder-in-every-loop becomes the launch bottleneck. Symbol: multiple request paths converge into one founder node.
- `s02`: key message is Launch is a repeatability gate, not another feature sprint. Symbol: MVP locks, then Launch gate points to repeatable growth.
- `s03`: key message is repeated problems should become systems. Symbol: recurring work is sorted into automation, delegation, and founder-judgment lanes.

## Assessment Criteria

- VI compliance: does it still feel like Founder Playbook?
- Concept fit: do the symbols encode the section key message?
- Understandability: can the viewer read the idea at phone size?
- Abstract style: does it avoid literal founder/person/software UI expression?
- Motion fit: should motion be routing pressure, gate transition, and lane sorting?
