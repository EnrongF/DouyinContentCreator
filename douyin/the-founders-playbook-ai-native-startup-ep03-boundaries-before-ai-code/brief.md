# Brief

Episode: `EP03 - 先定边界，再让 AI 写`

Mental upgrade:

```text
AI 写得越快，越要先把产品边界和上下文写清楚。
```

Core idea:
- MVP is still evidence-gathering, not full-product construction.
- AI-era technical debt is not only bad code; it is also boundary, architecture, and context drift.
- Before AI coding sessions, define what the MVP solves, what it deliberately does not solve, and what evidence justifies adding new scope.

Deferred:
- Launch operating systems belong to EP04.
- Security/compliance and hardening details are not taught here.
- PMF measurement frameworks are not introduced.
