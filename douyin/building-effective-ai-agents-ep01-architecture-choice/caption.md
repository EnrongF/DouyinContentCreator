# Caption

别急着问“能不能做 Multi-Agent”。

Multi-Agent 不是 Single Agent 的升级版。

真正要先分清的是：架构、协调、工作流。

Single Agent：一个 Agent 负责目标。  
Multi-Agent：核心是协调，hierarchical 属于集中式协调。  
Agentic Workflows：核心是结构，sequential / parallel 是 workflow pattern。  

而且 PDF 提醒：Multi-Agent 可能消耗单 Agent 约 10-15 倍 Token。
