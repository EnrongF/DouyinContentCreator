## Caption Thesis
The benchmark frames Harness Engineering as the key transition from AI that can talk to AI that can reliably get work done.

It uses a three-layer progression:
- Prompt Engineering: make the model understand the instruction.
- Context Engineering: make the model see the right information.
- Harness Engineering: make the model continuously, reliably, and goal-directedly act in the real world.

It defines Harness as the execution skeleton around the model, not a model feature.
