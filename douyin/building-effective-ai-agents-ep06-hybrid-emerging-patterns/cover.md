## Cover Logic

The cover sells the decision value: hybrid architecture is not the first move.
It should be used only after the system exposes evidence that routing,
specialists, workflow structures, or evaluator loops are needed.

The cover must not imply Anthropic endorsement. Source identity is attribution
only.
