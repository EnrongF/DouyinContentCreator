# Episode Brief

## Episode

EP06: 什么时候用混合架构?

## Rebuilt Promise

Hybrid architecture is not a starting architecture. It is an evidence-driven composition that appears after a narrow system exposes routing, specialization, parallel exploration, evaluation, or escalation needs.

## Keep

- Real-world evolution path: single agent -> routing -> specialized agents -> multi-agent coordination -> evaluator agents.
- Hybrid strategies combine supervisors, parallel processing, dynamic routing, and multi-agent escalation.
- Dynamic agent generation and peer-to-peer networks are emerging patterns, not mature defaults.
- Decision axes: control, domain complexity, resources, time-to-market, domain expertise, business value.
- Cost caveat: multi-agent systems can use roughly 10-15x more tokens than single agents.

## Move

- Full implementation tutorial.
- Detailed framework comparison.
- Deep context-management mechanics already handled by EP05.

## Source Logic Gate

Hybrid must be labeled as a combination across existing source layers. It must not flatten the source taxonomy:

```text
Single-agent systems
Multi-agent coordination concepts
Agentic workflow structures
```
