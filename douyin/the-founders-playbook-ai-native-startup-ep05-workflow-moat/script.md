# Script

很多人讲 AI 创业的护城河，第一反应是：我用了哪个模型。

但到规模化阶段，模型权限本身很难成为护城河。别人也能接入相似的能力。

真正开始拉开差距的，是业务流程里一层一层沉淀下来的细节。

比如，你知道这个行业的例外情况；你的系统接住了真实用户的行为。

你的流程连上了客户原来的工具，也留下了真实协作的痕迹。

这些东西不是一句提示词，也不是换一个模型就能复制。

它们会变成上下文、数据、集成、习惯，最后变成切换成本。

所以，这一集不要问：我们是不是用了 AI？

要问：我们的 AI 系统里，沉淀了哪些只有我们才有的业务细节？

这才是 AI-native 公司在规模化以后，可能长出护城河的地方。
