# Extraction

Store source maps, structured notes, and extracted concepts here.

Extraction is also where the source value inventory starts. Do not wait until scripting to decide what matters.

## Naming
Use descriptive article slugs so multiple research transforms can coexist.

Pattern:
- `<source-or-topic-slug>.source-map.md`

Required value inventory:
- Core concepts.
- Source-defined terms and categories.
- Diagrams, tables, metrics, examples, and artifacts.
- Process steps, failure modes, caveats, and boundary conditions.
- Practical implications for the target audience.
- Initial value tag for each item: non-cuttable, episode-core, supporting, move-to-later, or omit.
