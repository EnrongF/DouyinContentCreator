Why agents fit research

Research is path-dependent: the next useful step depends on what was just discovered.

03

Open-ended work

The article argues that complex research cannot be hardcoded into a fixed path because the right route changes as new leads appear.

Autonomous turns

The model must decide which direction to pursue across many tool calls instead of executing a linear one-shot pipeline.

Human-like investigation

Good research continuously updates the plan, follows tangential connections, and pivots when intermediate findings change the landscape.

Article reasoningDesign implication
Search is compression: distill insight from a vast corpus.Subagents act as parallel compressors, then return the most important tokens to the lead agent.
Separate contexts reduce path dependency.Each subagent can follow a different trajectory with distinct tools, prompts, and evidence.
Groups of generally intelligent agents can exceed individual limits.Coordination becomes the main architecture problem after model capability crosses a useful threshold.

Search as compression

The system distills insight from a large corpus by letting subagents explore and then compress their findings.

Path dependency

Research changes as evidence appears, so a one-shot pipeline cannot precompute the right route.

Separate contexts

Each subagent can follow a different trajectory without polluting the lead agent's working context.

Prompting principles, part 1: observe behavior, delegate clearly, and scale effort.

Semiconductor shortage failure example

When the lead gave vague instructions like "research the semiconductor shortage," one subagent explored the 2021 automotive chip crisis while two others duplicated work on current 2025 supply chains. The fix was sharper division of labor.

Evaluation

Evaluate whether agents reached the right outcome through a reasonable process.

09
Rubric itemQuestion the judge answers

Evaluation details from the article

  • Start immediately with small samples; Anthropic began with about 20 real-usage queries.
  • Early prompt tweaks can move success from 30% to 80%, so small evals can reveal large effects.
  • A single LLM judge call producing 0.0-1.0 scores and pass-fail worked better than multiple judges.
  • Human testers caught source selection bias toward SEO-optimized content farms over academic PDFs and personal blogs.
  • Small lead-agent prompt changes can unpredictably alter subagent behavior, so teams must evaluate collaboration patterns, not only individual outputs.
Production reliability

The prototype-to-production gap is mostly about state, tracing, and deployment.

10
ChallengeWhy it matters for agentsAnthropic response
Stateful executionAgents run across many tool calls; restarts are expensive and frustrating.Durable execution, retries, checkpoints, and resume from failure.
Tool failure adaptationAgents may encounter failing tools mid-run.Tell the model when a tool is failing so it can adapt, then combine that adaptability with deterministic safeguards.
Dynamic decisionsSame prompt can lead to different tool paths and sources.Full production tracing to diagnose bad queries, poor source choice, or tool failures.
Privacy-aware observabilityTeams need behavior insight without reading user conversations.Monitor decision patterns and interaction structures.
DeploymentAgents may be mid-process when code, prompts, or tools update.Rainbow deployments keep old and new versions running during gradual traffic shift.
Synchronous bottleneckLead waits for each subagent set; subagents cannot coordinate in real time.Async execution is a likely future improvement, but adds state consistency and error propagation challenges.

Takeaways

Agent quality is architecture, prompts, tools, evals, and operations working together.

13

Architecture

Use orchestrator-worker when breadth and independent exploration dominate the task.

Prompting

Encode effort budgets, delegation boundaries, tool-selection heuristics, and stopping behavior.

Tools

Tool metadata is a product surface. Poor descriptions materially increase failures and latency.

Evaluation

Judge outcomes with flexible rubrics; combine small evals, LLM judges, and human testing.

Reliability

Build durable execution, checkpoints, tracing, privacy-aware observability, and careful deploys.

Economics

Use multi-agent systems where task value justifies about 15x chat token usage.
