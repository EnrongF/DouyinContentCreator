Execution boundary

The model can be outside; the control plane and credentials cannot.

05

Delegate pattern

Harness describes actions running through a Delegate: a lightweight worker inside the customer's environment. The agent issues an instruction; the Delegate executes it inside the perimeter and returns the result.

Secret boundary

Secrets are decrypted inside the Delegate, not in the agent context window, model provider memory, or audit log. This is the practical difference between arbitrary access and governable execution.

Skills layer

Skills translate user intent into correct Harness workflows.

07

Problem

Raw tool access is not enough. A user should not need to know Harness resource schemas, org/project paths, pipeline internals, or which API maps to which task.

Pattern

Harness Skills are structured instruction files layered over MCP. They guide Claude Code, Cursor, GitHub Copilot, and other assistants to create, operate, debug, and govern CI/CD workflows through natural language.

Operating model

The winning pattern: many coding agents, one delivery control plane.

11

Distributed development

Teams may use Cursor, Claude Code, Copilot, Codex, or future agents. That diversity is healthy for code creation.

Centralized delivery

Software delivery needs one policy set, one audit trail, one credential boundary, and one place where evidence is retained. Whichever coding agent writes the code, deployment passes through the same harness.

Reusable pattern

Agent harness engineering is a general architecture pattern.

13

Context boundary

Expose enough context for good decisions, but not secrets or irrelevant noise.

Tool boundary

Reduce tool count, clarify resource types, and dispatch through registries.

Execution boundary

Run actions inside the enterprise environment where credentials belong.

Policy boundary

Put RBAC, OPA, approvals, and scorecards in the path of action.

Evidence boundary

Write durable records that auditors and incident reviewers can trust.

Skill boundary

Turn natural-language intent into safe workflows, not raw endpoint calls.
