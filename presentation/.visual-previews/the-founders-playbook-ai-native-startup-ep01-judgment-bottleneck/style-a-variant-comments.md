# Style A VI / Content-Fit Rebuild Comments

Slug: `the-founders-playbook-ai-native-startup-ep01-judgment-bottleneck`

## Design Correction

The prior rebuild correctly learned from the six covers, but it over-applied the
cover structure. Visual identity and page design are different layers:

- **Visual identity** should stay stable: warm black field, cream Chinese
  headline, amber episode badge, orange/cyan/amber chips, source language, quiet
  attribution, rounded humanist Chinese typography.
- **Partial scene design** should change by content: bottleneck map, wrong path,
  execution lanes, early judgment gate, accelerator/steering split, lifecycle
  gates, retained execution layer, final binary decision, demo/demand gate.

The source-proof shelf is a VI asset and trust device. It should not become the
default layout for every scene.

## Rebuilt Choice Set

1. `A1 VI-led Content Modules`: strongest series consistency; content-specific
   center modules, but still close to the cover system.
2. `A2 Balanced VI + Content Fit`: same VI layer, stronger content-specific scene
   mechanics. Recommended.
3. `A3 Source-fit Content Modules`: source-trust tone, but source proof appears
   only where it fits the claim; other scenes use different structures.

## Recommendation

Lock **A2 Balanced VI + Content Fit** unless the priority is maximum source
seriousness.

Reason:
- It complies with the confirmed VI without flattening every page into one
  cover layout.
- It assigns a distinct visual job to each major beat.
- It is the most suitable base for Remotion because each scene already maps to a
  semantic motion: path bend, lane activation, gate shift, control split,
  lifecycle reveal, binary hold.

## Symbol / Motion Pass

Added after review:
- A reusable scene-symbol grammar for bottleneck, wrong path, execution lanes,
  gate shift, control split, lifecycle, retained layer, judgment node, binary
  decision, and demo/demand gate.
- Symbols appear as local meaning markers, not as decoration.
- Preview motion is semantic: line sweep, wrong-path draw, lane activation,
  gate shift, control pulse, lifecycle reveal, decision emphasis, and blocked
  demand movement.
- Reduced-motion fallback is preserved through `prefers-reduced-motion`.
