## Applied Principle

Visual identity is the shared language. Scene design is the content-specific
mechanism.

Use the confirmed six-cover VI for:
- background field;
- typography;
- badge/chip/source-mark treatment;
- warm/technical accent palette;
- source-trust tone.

Change the visual structure by content:
- bottleneck claim -> blocked work lane;
- wrong direction claim -> bent path;
- execution compression -> four activated lanes;
- judgment emerges early -> gate shifts left;
- AI as accelerator -> control split;
- lifecycle taxonomy -> ordered stage gates;
- caveat -> retained execution layer;
- final takeaway -> binary decision hold.

## Symbol And Motion Rule

General symbols can repeat across the episode, but only as content markers:

- bottleneck symbol for blocked work;
- path symbol for wrong direction or acceleration;
- lanes symbol for parallel execution;
- gate symbol for early judgment or stage entry;
- control symbol for accelerator/steering distinction;
- lifecycle symbol for source order;
- layer symbol for execution-retained caveats;
- node symbol for founder judgment;
- binary symbol for speed-vs-judgment takeaway;
- demo symbol for the next episode validation gate.

Motion should explain a state change, not decorate the frame.
