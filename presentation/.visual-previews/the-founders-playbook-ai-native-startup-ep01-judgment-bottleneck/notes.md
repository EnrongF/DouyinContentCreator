# Visual Preview Notes

## Source Constraints

- The visual must preserve the source lifecycle: `Idea -> MVP -> Launch -> Scale`.
- The episode claim is a bottleneck shift, not execution disappearance.
- `油门 / 方向盘` is a synthesis metaphor, not a source diagram.
- No unverified startup statistics or founder examples are used.

## Preview Scope

These files preview visual language only:
- `style-a.html`
- `style-b.html`
- `style-c.html`
- `index.html`

They do not implement Remotion, render video, or create Douyin package files.

## Frame Constraints

- Primary video format: `1080x1920` vertical.
- Bottom subtitle area is reserved.
- Top metadata/progress area is reserved.
- Cover crop constraints are separate and should be checked later at `1080x1440`.
