## What The Source Covers

The PDF reframes the startup lifecycle for AI-native founders:

- startup lifecycle rebooted for 2026;
- founder role shifting from individual contributor to orchestrator of agents;
- Idea stage: research, customer discovery, competitive analysis, disconfirming evidence;
- MVP stage: scope, architecture, AI technical debt, security, measurement, PMF evidence;
- Launch stage: repeatable growth, production hardening, founder bottleneck removal;
- Scale stage: governance, enterprise readiness, GTM, workflow lock-in, data moat;
- resources and Claude-specific founder stories.

The source is structured around four major stages:

```text
Idea -> MVP -> Launch -> Scale
```

## Why This Source Matters

This source is relevant because it provides a founder-facing operating model for AI-native startups, not just a generic statement that "AI changes startups."

High-value mental-model candidates:

- AI compresses execution, so the bottleneck shifts to judgment.
- Founders should keep sense-making ahead of building.
- A prototype is not validation; user conversations and evidence are validation.
- AI-era MVPs need explicit architecture, scope, and context files to avoid agentic technical debt.
- Launch requires replacing founder attention with systems.
- Scale requires turning founder knowledge, workflows, integrations, and user data into defensibility.
