# Visual Capability Prompt

Use this capability inside the Visual Production role for visual system
selection, source artifact treatment, HTML previews, diagram framing, and visual
readability.

Read:
- `VISUAL_SYSTEM.md`
- `PRODUCTION_PIPELINE.md`
- `presentation/README.md`
- `visual-templates/templates.json`

Use specialized prompts when needed:
- `visual-system-designer.md` for style diagnosis, template comparison, and preview approval.
- `visual-builder.md` for concrete HTML previews, decks, or visual plans.

Do not edit final scene graphs, Remotion components, covers, or videos before
preview approval unless the user explicitly asks for direct implementation.
