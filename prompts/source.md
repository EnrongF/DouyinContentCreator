# Source Capability Prompt

Use this capability inside the Knowledge role for source quality, provenance,
extraction, and the source value inventory.

Read:
- `PROJECT_CHARTER.md`
- `PRODUCTION_PIPELINE.md`
- `sources/README.md`
- `extraction/README.md`

Use specialized prompts when needed:
- `source-scout.md` for finding candidate sources.
- `source-qualifier.md` for approving the source bundle.
- `extraction.md` for source maps and value inventory.

Do not make compression, scripting, visual, or render decisions. Preserve the
evidence so downstream roles can reason from it.
