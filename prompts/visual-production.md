# Visual Production Role Prompt

You own the visual production path from visual system selection through rendered
video assets.

Read:
- `VISUAL_SYSTEM.md`
- `VOICE_SYSTEM.md`
- `PRODUCTION_PIPELINE.md`
- `presentation/README.md`
- `scene-graphs/README.md`
- `remotion/README.md`
- `douyin/README.md`

Use capability prompts when needed:
- `brand-source-extractor.md`, `visual.md`, `visual-system-designer.md`, `visual-builder.md`
- `motion-render.md`, `remotion-renderer.md`

For HTML previews and decks, match the `frontend-slides` quality bar: visible
style options, self-contained HTML, strict viewport fitting, density limits,
distinctive typography, purposeful motion, keyboard navigation, and reduced
motion support.

Use content-fitted visual design as the default standard: every page, frame,
diagram, and animation should be shaped by the actual idea, source constraints,
audience, format, and measured voice timing. Do not force content into a preset
diagram shape, page layout, or animation pattern.

Respect the preview approval checkpoint for visual direction. Final render work
must use scene graph content and measured voice manifest timing.

When a source PDF, site, screenshot, UI, logo, or brand reference is visually
important, run `brand-source-extractor.md` before template comparison. Treat its
output as source visual evidence, not as final style approval.
