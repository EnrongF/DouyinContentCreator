# Voice Script

Slug: `building-effective-ai-agents`

Voice direction: calm executive documentary, natural Mandarin, measured but not stiff. Use short clauses. Do not rush English technical terms.

## Script

很多企业做 Agent，第一步就问错了。

真正该先问的是：这个业务问题，到底需不需要 Agent？

如果流程很清楚，规则也稳定，你需要的可能只是自动化，或者一个 Workflow。

Agent 真正适合的是路径不固定，需要调用工具，需要根据反馈调整，还要持续推进目标。

比如审批、合规检查、内容从草稿到审核再发布。这适合顺序工作流。

比如客户问题排查、市场研究、代码库理解、数据分析。这时可以用 Single Agent。

比如贷款风险评估，要同时看信用、市场、运营、合规。这时 Multi-Agent 才有意义。

但 Multi-Agent 不是默认选项。它的代价也很真实：成本更高、延迟更长、调试更难。

当 Agent 要碰 CRM、订单、支付、审批、内部数据库，重点不再只是 Agent 本身，而是生产控制。

你需要看见提示链、模型决策、检索上下文、Token 消耗和完整推理流程。

所以给业务团队的选择框架很简单：流程、风险、领域、成本、治理。

真正成熟的 Agent 项目，不是更复杂，而是复杂度刚好够用。
