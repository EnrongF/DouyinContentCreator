# Series

Store topic-level series maps when a source or topic is too dense for one artifact.

Use a series map before scripting when one video would over-compress important value, rush the voice, or force too many visual focus changes.

Pattern:
- `<slug>.series.md`

Must include:
- Topic promise.
- Audience.
- Series type: single artifact, mini-series, or full series.
- Source value inventory summary.
- Episode list with one mental upgrade per episode.
- For each episode: hook angle, core idea, practical takeaway, source concepts retained, and bridge to the next episode.
- Notes on what was intentionally moved out of the current episode to preserve clarity and value.

Hierarchy:

```text
source value
-> topic
-> series
-> episode
-> section
-> voice paragraph
-> visual focus moment
```
