# Synthesis

Store synthesized briefs here.

## Naming
Use descriptive article slugs so multiple research transforms can coexist.

Pattern:
- `<source-or-topic-slug>.brief.md`

Store the merged brief and thematic summary here.

Each brief should preserve the value inventory from extraction and reorganize it into:
- Candidate mental upgrades.
- Candidate episode splits.
- Non-cuttable source material.
- Supporting material that can be cut if pacing is tight.
- Material that should move to later episodes instead of being over-compressed.
