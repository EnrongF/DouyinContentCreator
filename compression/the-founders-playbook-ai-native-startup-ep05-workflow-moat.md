## Episode Position

Episode 5 covers the Scale stage. Episode 4 ended with systems replacing default
founder routing. Episode 5 asks what happens after systems exist: what does the
company learn, integrate, and accumulate that competitors cannot copy by simply
using the same model?

```text
Launch: repeated work becomes systems.
Scale: systems accumulate workflow specificity.
```

## Episode Promise

Help founders stop treating AI access as defensibility. At scale, the useful
question is what unique operational detail the company is accumulating through
real workflows.

One-sentence Chinese promise:

```text
AI-native 公司的护城河，不是模型权限，而是业务流程里沉淀下来的细节。
```

## Exact Mental Upgrade

Models and tools can be copied. Workflow-specific context is harder to copy when
it is accumulated through real users, repeated decisions, integrations,
feedback, governance, and operational memory.

Compressed mental upgrade:

```text
护城河不是“用了 AI”，而是系统里沉淀了别人拿不走的业务细节。
```

## Source Value Budget

Non-cuttable:
- Scale is a different stage from Launch.
- Defensibility comes from accumulated specificity, not generic AI usage.
- Useful specificity includes domain knowledge, workflow depth, integrations,
  behavioral data, user lock-in, and reduced founder dependence.
- Strong moat claims remain conditional without verified examples.

Episode-core:
- Contrast: same model access vs workflow-specific accumulation.
- Show the accumulation loop: real work -> context -> integration -> data ->
  switching cost.
- Practical audit: what is now inside your system that was not inside it last
  month?

Supporting:
- Governance and enterprise readiness.
- Mature operations.
- Systematic growth.

Move / omit:
- Named startup examples until verified.
- Compliance checklist and enterprise procurement details.
- Full data moat legal/technical tutorial.
- Claims about current Claude product availability.

## Compression

### Core Claim

```text
规模化以后，真正难复制的不是你调用了哪个模型，而是你的业务流程沉淀了多少独特上下文。
```

### Compact Mental Model

```text
工作流才会长出护城河。
```

Meaning:
- AI capability is increasingly available to competitors.
- A product becomes harder to copy when its workflows contain domain-specific
  decisions, integrations, user behavior, and operational memory.
- The founder's job shifts from routing work to designing accumulation loops.

### Suggested Scene Spine

1. **Model access is not moat**
   - Visual idea: two companies use the same model; no separation.
   - Focus phrase: `不是模型权限`.

2. **Workflow starts accumulating**
   - Visual idea: workflow loop collects decisions, edge cases, and context.
   - Focus phrase: `业务流程里的细节`.

3. **Specificity layers**
   - Visual idea: domain knowledge, integrations, behavioral data, governance,
     user habits become layered assets.
   - Focus phrase: `一层一层沉淀`.

4. **Copy gap**
   - Visual idea: competitor can copy tool access but not operational memory.
   - Focus phrase: `复制不了你的细节`.

5. **Final question**
   - Visual idea: audit card asks what the system learned this month.
   - Focus phrase: `系统里沉淀了什么`.
