## Episode Promise

Help the viewer stop treating a working Demo as evidence that the market wants the product.

One-sentence Chinese promise:

```text
Demo 可以帮你问问题，但不能替你证明有人要。
```

## Exact Mental Upgrade

AI makes it easy to collapse the distance from idea to prototype. That speed is useful only after the founder has enough evidence that a real, specific problem exists and that the proposed solution addresses it.

Compressed mental upgrade:

```text
Demo 不是验证。真正的验证，是用户在谈真实痛点时给出的证据。
```

## Target Audience

- Founder using AI tools to move from idea to prototype.
- Solo builder who can quickly produce demos but has not yet validated demand.
- Product operator trying to separate polite feedback from real user pain.
- Technical founder tempted to start coding before customer discovery.

## Episode Spine

1. AI shortens the path from idea to Demo.
2. The source warning: building can be mistaken for validation.
3. Idea-stage exit condition: real, specific problem; actual solution fit; enough signal to justify MVP.
4. Use the Demo as a conversation prop, not as proof.
5. Practical test: listen for past behavior, current workaround, frequency, severity, and evidence that challenges the hypothesis.
6. Takeaway: the question is not "Can I build this?" but "What did real users reveal?"

## Retained Source Value

- Idea stage is research-oriented validation before committing resources to building.
- The source-defined exit condition is problem-solution fit.
- A working prototype is not validation.
- Prototype should be used as a pressure-testing prop in conversations with potential users.
- Customer discovery should ask about actual past behavior, not future-facing politeness.
- Disconfirming evidence matters because AI can also help founders build a convincing case for a bad idea.
- A lightweight prototype should test a single core interaction after validation work, not become an excuse to keep building.

## Non-Cuttable Claims And Caveats

- Do not imply demos are bad. The caveat is that demos are tools for learning, not proof by themselves.
- The Idea-stage question is `Is this worth building?`
- Problem-solution fit must come before MVP build confidence.
- Evidence should come primarily from real human conversations and observed problem context.
- Claude / Anthropic product surfaces are source examples, not universal startup law.
- Do not use the unverified startup failure statistic.

## Source-Fidelity Risks

Risk: turning the episode into generic "talk to users" advice.

Handling:
- Anchor the risk in AI-native build compression: the prototype is now too easy to create and too easy to over-trust.

Risk: making customer praise sound worthless.

Handling:
- Distinguish polite reaction from evidence. A positive reaction can matter only when it reveals real behavior, severity, frequency, or willingness to change.

Risk: over-teaching customer discovery.

Handling:
- Keep the episode to one rule: use the Demo to expose evidence, not to collect compliments.

Risk: vendor-shaped doctrine.

Handling:
- Avoid Claude product walkthroughs in the public script unless used as source attribution.

## Compression

### Core Claim

```text
AI 让 Demo 更容易做出来，但真正决定能不能继续的，不是 Demo 存不存在，而是用户有没有暴露真实问题。
```

### Compact Mental Model

Working model:

```text
Demo 是道具，不是证据。
```

Meaning:
- A Demo helps users react to something concrete.
- It does not prove demand by existing.
- The evidence is in what users reveal: current behavior, workaround, pain frequency, severity, budget, urgency, and contradiction.
- The founder must ask questions that make the hypothesis easier to disprove, not easier to defend.

This model is approved for compression, but it is **not final voice copy**. Voice Design should test whether `道具` sounds too dismissive and may use `谈话工具` or `验证工具` if needed.

### Practical Conversation Filter

Use the Demo to ask:

```text
上一次你遇到这个问题是什么时候？
现在怎么解决？
这个问题多久出现一次？
不解决会造成什么损失？
这个 Demo 哪里没有解决你真正的问题？
```

Compression guardrail:
- Do not present this as a complete interview script.
- Do not imply five questions are sufficient proof.
- Use it as a signal filter for the episode's takeaway.
