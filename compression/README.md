# Compression

Store topic-level cognition compression artifacts.

Each file should turn source-grounded extraction into one compact mental model, decision frame, ladder, matrix, or operating principle.

If the source material contains more than one mental upgrade, do not compress it into a thin summary. Create or update a series map first, then compress only the selected episode.

Compression rate is managed as a value budget:
- Short, 15-30 seconds: one contrast, one source-faithful idea, one takeaway.
- Standard, 45-90 seconds: one mental model, three to five named parts, one example or artifact, one takeaway.
- Deep technical, 90-180 seconds: one mental upgrade with sections; use only when fidelity would suffer in a shorter format.

Value tags:
- Non-cuttable: required for truth, source fidelity, or the core mental model.
- Episode-core: required for this episode's mental upgrade.
- Supporting: useful if pacing allows.
- Move-to-later: valuable but belongs in another episode.
- Omit: low-value for this audience or redundant after compression.

Pattern:
- `<slug>.md`

Must include:
- Core claim.
- Target audience.
- Compression level and value budget.
- Mental model.
- Scope decision: single artifact or series episode.
- What to preserve from original sources.
- What to omit and why.
- What should move to another episode if value would be over-compressed.
- Non-cuttable claims, caveats, terms, metrics, or artifacts.
- Expected value loss from the selected compression level.
- Suggested scene spine.
